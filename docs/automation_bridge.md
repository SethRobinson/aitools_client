# Automation control server (editor testing harness)

Deep-dive for `Assets/_Script/Automation/*` (the loopback HTTP bridge that lets scripts compile, drive and inspect the editor and AI Chat). The "prefer the bridge" rule and the enable menu are in `AGENTS.md`; when you add an endpoint, document it here.

Moved verbatim from AGENTS.md on 2026-09-13 (bullet style kept); update this file when the feature changes and keep the AGENTS.md index entry to one or two lines.

## Files

- `Assets/_Script/Automation/AutomationBridge.cs` (runtime): static seam shared by the editor server and the play-mode driver (runtime can't reference editor types, so shared state lives here).
- `Assets/_Script/Automation/AutomationDriver.cs` (runtime MonoBehaviour): registers with the bridge; implements settings-open, chat send, the "fully idle" query, save-chat-image, and screenshot capture. In standalone builds it self-spawns when `-enable_automation` is on the command line; in the editor the controller spawns it on entering play.
- `Assets/_Script/Automation/Editor/AutomationController.cs` (editor, `[InitializeOnLoad]`): a raw `TcpListener` on `http://127.0.0.1:8772/` (TcpListener, not HttpListener, to avoid the Windows HTTP.sys URL-ACL/admin requirement). The "rebuild & restart" state machine persists across domain reloads via `SessionState` and advances on `afterAssemblyReload`. OFF by default - enable with **Tools > RT Automation > Enable Control Server** (EditorPrefs-persisted). Requests carrying an `Origin` header, or a `Host` that is not loopback, get 403 (since 2026-09-13): a browser tab could otherwise `fetch()` the loopback port as a CORS simple request (no preflight) and drive `/screenshot`, `/save`, `/chat_import_*` and `/chat`; curl / PowerShell / scripts send neither.

## Endpoints

`POST /pic_cancel` (body `index=<n|latest>`, default latest) cancels that chat image's render through the Pic's own "clear jobs and errors" path (ComfyUI `/interrupt` plus the queue delete) and reports `cancelled:true` when a render was running or queued. AI Chat's Stop button deliberately never touches canvas renders, so this is the way to test render cancellation.

`GET /status` also carries `compileFailed` (true while the editor's scripts have compile errors). A `/rebuild` whose compile fails ends with `rebuilding:false`, `playing:false` and `compileFailed:true` instead of sitting in the `play` stage forever; fix the error and POST `/rebuild` again.

Endpoints (loopback only): `GET /status` (playing/focused/compiling/driverReady/idle/chatActive/ready/stage; `focused` mirrors runtime `Application.isFocused`), `POST /rebuild` (exit play → recompile → re-enter play, no clicks), `POST /play`, `POST /stop`, `POST /settings` (body `tab=<general|configuration|comfyui|audio|web|llm>`; opens the unified Settings panel), `POST /llm_settings` (opens the advanced LLM Settings panel; optional body `instance=<instance-name substring>` also selects that instance row, scrolls the list to it, and returns its display string, so a test can screenshot/click one instance's provider controls), `POST /server_settings` (body `id=<serverID>`; opens that server's Overrides panel), `POST /focus_input` (body `name=<hierarchy-path substring>` matched case-insensitively against full transform paths like `AppSettingsPanel/.../UrlRow/Input`, optional `selectall=<true|false>`; focuses the first matching active `TMP_InputField`, returns the matched path plus `caretGraphic` = whether its caret/selection renderer exists), `POST /open_chat`, `POST /chat` (body = message text; opens chat + sends one turn; returns ok:false if a busy gate refused the send - poll `/status` idle and retry), `POST /chat_stop` (presses AI Chat's Stop button: aborts the streaming turn, pending inspections/auto-resumes, in-flight web fetches and audio generation; the reply carries `stopped:true|false` = whether anything was actually running, since the handler is a no-op when the button would be greyed), `POST /chat_import_video` (body `path=<file>` plus optional `start=<seconds>`, `duration=<seconds>`, `fps=<n>`, `audio=<true|false>`, and `save_wav=<true|false>` to also land the range's audio as a WAV Audio bubble, and `normalize=<true|false>` to override the clip audio normalization setting for this import; opens AI Chat and imports a clipped local video as a Movie bubble), `POST /chat_import_image` (body `path=<file>`; opens AI Chat and imports a local still image as a `#N (you)` bubble - lets scripted tests stage photo references), `POST /chat_attach` (body `path=<file>`; stages a still as a PENDING attachment for the next `/chat` send - the REAL attachment path with thumbnail strip/captioning/`attachment="N"` resolution, unlike `/chat_import_image` which promotes straight to a bubble), `POST /chat_main_llm` (body `name=<instance-name substring|default>`; selects the footer Main LLM override - persists like the dropdown, so tests must restore `default`/the prior instance when done), `POST /chat_web` (body `enabled=<true|false>`, omit to read; flips the AI Chat header "Web" checkbox that gates the web_* skills - persists, restore it when done), `POST /chat_compact` (body `mode=<summarize|truncate>` default summarize, `keep=<n>` exchanges kept verbatim default 2; runs AI Chat's Compact - summarize is async, poll `/status` idle), `POST /paste` (body `target=<chat|app>` default app; runs the Ctrl+V clipboard paste - the bridge cannot inject keystrokes - "chat" = AI Chat attachment-zone paste where clipboard files import like drops and videos open the clip chooser, "app" = workspace paste), `GET /chat_images` (JSON: index/w/h/busy/movie/captionPending/captionShort/captionLong and `moviePath` for Movie bubbles; for movies w/h are the CLIP's ffprobed dimensions, not the Pic's placeholder sprite), `POST /movie_state` (body `index=<n|latest>`; PicMovie playback telemetry for a Movie bubble - wantPlaying/isPlaying/time/seekPending/queuedSeek/kick counters - for verifying play/seek behavior without screenshots), `POST /chat_thinking` (body `action=<open|close|toggle|status>`, default status; drives the floating Thinking window for the LATEST assistant bubble through the same code path as a click on its `[thinking]` marker and reports `open`/`live`/`title`/`chars`/`showingLatest`/`layout` (anchored pos, size, parent canvas rect)/`streaming` - `open` mid-stream then poll `status` to watch `chars` grow), `POST /save` (body `index=<n|latest>` + `path=<file>`; writes a PNG via `PicMain.SaveFile`), `POST /screenshot` (body `path=<file>` + optional `x,y,w,h` top-left region; full game view if omitted). `POST /click` (body `x=<px>`, `y=<px>` in the same top-left game-view pixel frame as `/screenshot`, optional `button=right` and `alt=<true|false>` (sets `AutomationBridge.SyntheticAltHeld` during the dispatch so alt-click UI like the clip chooser's marker snap is testable without OS keyboard focus); raycasts the UI under the point and dispatches pointer down/up/click, returning the hit hierarchy path - use it to exercise click-driven UI such as the chat's `[skill: X]` markers or buttons after measuring their position on a screenshot). `POST /scroll` (body `x=<px>`, `y=<px>` in the same frame, optional `dy=<wheel notches>`, default -3 = down, positive = up; dispatches a mouse-wheel scroll event to the ScrollRect under the point - the way to page long panels such as LLM Settings, whose scrollbar track does not react to synthetic clicks). Request bodies for `/settings`, `/llm_settings`, `/scroll`, `/server_settings`, `/chat_import_video`, `/chat_compact`, `/paste`, `/save`, and `/screenshot` are `key=value` lines.

## The idle flag, async file writes and editor prefs

The `idle` flag ANDs every AI Chat busy gate (streaming, forced-main wait, compact summary, sidecar captions/inspections, auto-resume, the skill-action pump) plus any chat-generated `PicMain` still rendering - so it only reports idle once an image turn has finished rendering on the GPU, not merely when the text stream ends. `/save` and `/screenshot` write files asynchronously (screenshot waits for end-of-frame); poll for the file. Recommended editor pref: **Script Changes While Playing = Stop Playing And Recompile** for deterministic reloads. While the automation driver is attached, `PicMovie` treats the app as focused for movie load/playback/seek logic (`AppFocusedForPlayback()`), so bridge-driven movie tests work with the editor in the background; audio unmuting still requires real OS focus.
